# 1.2 Implement a Softmax classifier

Softmax是一种激活函数，它可以将一个数值向量归一化为一个概率分布向量，且各个概率之和为1。

Softmax可以用来作为神经网络的最后一层，用于多分类问题的输出。Softmax层常常和交叉熵损失函数一起结合使用。

SoftMax 是把得分转换成了概率。公式如下：

S(yi)=eyi∑jeyjS(y_i) = \dfrac{e ^ {y_i}}{\sum\limits_{j} e ^ {y_j}} S(yi​)=j∑​eyj​eyi​​

损失函数就是根据交叉熵套了个 −log⁡(x)-\log(x)−log(x)：

Li=−log⁡(eyi∑jeyj)L_i = -\log\left(\dfrac{e ^ {y_i}}{\sum\limits_{j} e ^ {y_j}}\right) Li​=−log​j∑​eyj​eyi​​​

loss 对每个 score 的梯度 = 预测概率 − 真实标签

∂L∂s=p−y\frac{\partial L}{\partial s} = p - y ∂s∂L​=p−y

# softmax_loss_naive

def softmax_loss_naive(W, X, y, reg):
    loss = 0.0 # 总损失
    dW = np.zeros_like(W) # 梯度
    num_classes = W.shape[1] # 类别数
    num_train = X.shape[0] # 批量大小
    for i in range(num_train):
        scores = X[i].dot(W) # s=XW
        scores -= np.max(scores) # 减去最大值
        p = np.exp(scores) # 计算 softmax 值
        p /= p.sum() 
        # 计算loss
        logp = np.log(p) 
        loss -= logp[y[i]]  
        # 计算梯度
        p[y[i]] -= 1
        for j in range(num_classes):
            dW[:, j] = X[i] * p[j]
    loss = loss / num_train + reg * np.sum(W * W)
    dw = dw / num_train + 2 * reg * W
    return loss, dW

# softmax_loss_vectorized

def softmax_loss_vectorized(W, X, y, reg):
    loss = 0.0
    dW = np.zeros_like(W)
    num_train = X.shape[0]
    s = X @ W # 矩阵乘法
    s = s - np.max(s, axis=1, keepdims=True) # 每一行减去最大值
    p = np.exp(s)
    p /= p.sum(axis=1, keepdims=True)
    loss = -np.sum(np.log(p[np.arange(num_train), y]))
    loss = loss / num_train + reg * np.sum(W * W)
    p[np.arange(num_train), y] -= 1
    dw = X.T @ p
    dw = dw / num_train + 2 * reg * W
    return loss, dW

# affine_forward

def affine_forward(x, w, b):
    """
    计算仿射（全连接）层的前向传播。

    输入 x 的形状为 (N, d_1, ..., d_k)，表示一个包含 N 个样本的小批量；
    每个样本 x[i] 的形状为 (d_1, ..., d_k)。我们会把每个输入展平成维度为
    D = d_1 * ... * d_k 的向量，再映射到维度为 M 的输出向量。

    参数：
    - x：输入数据，numpy 数组，形状 (N, d_1, ..., d_k)
    - w：权重矩阵，形状 (D, M)
    - b：偏置向量，形状 (M,)

    返回一个元组：
    - out：输出，形状 (N, M)
    - cache：缓存 (x, w, b)，供反向传播使用
    """
    out = None
    out = x.reshape(x.shape[0], -1) @ w + b
    cache = (x, w, b)
    return out, cache
  • x 需要 reshape 之后才能矩阵形状符合相乘的要求

# affine_backward

def affine_backward(dout, cache):
    """
    计算仿射（全连接）层的反向传播。
    输入：
    - dout：上游梯度（损失对层输出的导数），形状 (N, M)
    - cache：元组，包含前向时缓存的：
      - x：输入数据，形状 (N, d_1, ... d_k)
      - w：权重，形状 (D, M)
      - b：偏置，形状 (M,)

    返回一个元组：
    - dx：损失对 x 的梯度，形状 (N, d1, ..., d_k)
    - dw：损失对 w 的梯度，形状 (D, M)
    - db：损失对 b 的梯度，形状 (M,)
    """
    x, w, b = cache
    dx, dw, db = None, None, None
    dx = dout @ w.T
    dx = dx.reshape(x.shape)
    dw = x.reshape(x.shape[0], -1).T @ dout
    db = np.sum(dout,  axis=0) # axis=0 相当于按列方向求和
    return dx, dw, db

普通 SGD

标准 SGD 更新是：

θt+1=θt−η∇L(θt)\theta_{t+1} = \theta_t - \eta \nabla L(\theta_t) θt+1​=θt​−η∇L(θt​)

问题在于：

  • 梯度有噪声（mini-batch）
  • 在某些方向上来回震荡
  • 收敛慢（尤其是“狭长峡谷”地形）

Momentum 的核心思想

灵感来自物理里的动量（惯性）：

一个物体不会立刻改变方向，而是会“延续之前的运动趋势”

所以我们引入一个“速度”变量 v：

vi+1=μvi−ηdwiWi+1=Wi+vi+1v_{i+1} = \mu v_{i} - \eta dw_i \\ W_{i+1} = W_i + v_{i+1} vi+1​=μvi​−ηdwi​Wi+1​=Wi​+vi+1​

  • vtv_tvt​：是动量缓存
  • μ\muμ ：动量系数（常见 0.9 / 0.99）
  • η\etaη 学习率

在不同方向的效果

  • 梯度方向一直一致 → v 累积变大 → 更新越来越快
  • 梯度来回变化（噪声方向）， 会抵消震荡

使用 SGD+Momentum 的更新规则通常会收敛得更快。

# RMSProp

RMSProp 是解决什么问题?

在学习 SGD / SGD + Momentum 时有一个核心问题：不同参数维度的梯度尺度差异很大

导致：

  • 某些方向更新过猛（震荡）
  • 某些方向更新过慢（收敛慢）

RMSProp 的核心目标：为每个参数自适应调整学习率

核心公式：

梯度计算

gt=∇L(Wt) g_t = \nabla L(W_t) gt​=∇L(Wt​)

二阶矩（平方梯度）滑动平均

st=ρst−1+(1−ρ)gt2s_t = \rho s_{t-1} + (1-\rho) g_t^2 st​=ρst−1​+(1−ρ)gt2​

参数更新

Wt+1=Wt−ηst+εgtW_{t+1} = W_t - \frac{\eta}{\sqrt{s_t}+\varepsilon} g_t Wt+1​=Wt​−st​​+εη​gt​

符号 含义
gtg_tgt​ 当前梯度
sts_tst​ 梯度平方的滑动平均（历史信息）
ρ\rhoρ 衰减率（常用 0.9）
η\etaη 学习率
ε\varepsilonε 防止除 0（如 10−810^{-8}10−8）

核心思想：用“历史梯度的大小”来调整学习率

情况 1：梯度一直很大

gt2很大→st很大→分母变大→实际学习率变小g_t^2 很大 → s_t 很大 → 分母变大 → 实际学习率变小 gt2​很大→st​很大→分母变大→实际学习率变小

效果：防止震荡 / 爆炸

情况 2：梯度很小

gt2很小→st很小→分母变小→实际学习率变大g_t^2 很小 → s_t 很小 → 分母变小 → 实际学习率变大 gt2​很小→st​很小→分母变小→实际学习率变大

# 2.1 Batch Normalization

为什么需要 BN?

机器学习更喜欢：

  • 特征 不相关
  • 均值 = 0
  • 方差 = 1

这样优化更容易收敛

核心问题：内部协变量偏移（ICS）

每一层的输入分布在训练过程中不断变化

原因：

  • 前面层的参数在更新
  • 后面层输入分布一直在“漂移”

BN 的核心思想：让每一层的输入分布稳定下来

    σB2=1m∑i=1m(xi−μB)2\sigma_B^2 = \frac{1}{m}\sum_{i=1}^m (x_i - \mu_B)^2 σB2​=m1​i=1∑m​(xi​−μB​)2

  3. 标准化

# 2.2 Dropout

Dropout 是一种用于防止过拟合（overfitting）的正则化方法。

在训练过程中：

  • 以概率 p 保留神经元（active）
  • 以概率 1 - p 将神经元输出置为 0（drop）

Dropout 可以理解为：

每一次训练，都是在训练一个“子网络”

  • 每个 mini-batch 都随机“删掉”一部分神经元
  • 相当于从完整网络中 采样一个子模型
  • 所有子模型共享参数

# max_pool_forward & backward_naive

max pooling（最大池化）是卷积神经网络中的一种下采样操作，它使用固定大小的窗口（例如 2×2 或 3×3）在特征图上按 stride 滑动，并在每个窗口内取最大值，从而生成更小的输出特征图。

它的本质是对局部区域做“最大值筛选”，因此可以看作一种非参数的降采样方法。

max pooling 的作用主要有两个方面：

  • 一是降低特征图的空间尺寸，从而减少计算量和参数传递的复杂度；

  • 二是保留局部区域的最强响应，使模型对轻微的平移、形变具有一定鲁棒性。由于只保留最大值，它会丢弃大量非显著信息，这种信息压缩在一定程度上具有正则化效果，但也会导致细节丢失，因此在语义分割等任务中不常单独使用。

前向传播的数学形式可以表示为：

y[n,c,i,j]=max0≤u<PH,0≤v<PWx[n,c,i⋅S+u,j⋅S+v]y[n, c, i, j] = max_{0 ≤ u < PH, 0 ≤ v < PW} x[n, c, i·S + u, j·S + v] y[n,c,i,j]=max0≤u<PH,0≤v<PW​x[n,c,i⋅S+u,j⋅S+v]

其中：

  • PH, PW 表示 pooling window 的高和宽
  • S 表示 stride
  • (i, j) 是输出位置
  • (u, v) 是窗口内部偏移

含义是：输出的每个位置 y[n, c, i, j]，等于输入对应局部窗口中的最大值。

反向传播的核心思想是：

max 操作的梯度只会传给“最大值所在的位置”，其他位置梯度为 0。

因为 max 函数在前向传播中只选择一个元素作为输出，因此在反向传播中，只有这个被选中的元素对 loss 有贡献。

其伪代码可以表示为：

for each pooling window:
    idx = argmax(window)
    dx[idx] += dout[current_output_cell]

整体来看：

  • forward：在局部区域内做最大值选择，实现信息压缩
  • backward：梯度只沿着最大值路径回传，实现稀疏梯度分配

因此 max pooling 可以理解为一种“硬选择机制”，它在前向传播中丢弃非最大信息，在反向传播中也只保留最大路径的梯度传递。

# Kaiming 初始化

（也常叫 He 初始化）是一种专门为 ReLU 及其变体激活函数 设计的参数初始化方法。它的目标很直接：

让神经网络在前向传播和反向传播时，数值尺度尽量稳定，避免层数一深就出现激活值或梯度越来越大、越来越小的问题。

它出自这篇论文：
He et al., Delving Deep into Rectifiers: Surpassing Human-Level Performance on ImageNet Classification (ICCV 2015)

为什么需要它

权重初始化情况 前向传播 反向传播 后果
过大 激活值越来越大 梯度可能爆炸 训练不稳定
过小 激活值越来越接近 0 梯度逐层衰减 难以学习

激活值”指的是：某一层神经元输出出来的数值，经过激活函数后的结果，也就是 激活值（activation）

Kaiming 初始化的思路是：

  • 根据当前层输入单元数 fan_in
  • 自动决定一个合适的方差
  • 让每层输出的尺度大致保持稳定

核心结论

对于使用 ReLU 的层，权重通常初始化为：

W ~ N(0, 2 / fan_in)

也就是说：均值是 0，方差是 2 / fan_in

这里的 fan_in 指输入维度数量：

  • 对全连接层，fan_in 就是输入特征数
  • 对卷积层，fan_in = 输入通道数 × 卷积核高 × 卷积核宽

所以标准差通常是：

std = sqrt(2 / fan_in)

为什么是 2

因为 ReLU 会把一半左右的负数截断成 0，这会让信号的方差变小。
Kaiming 初始化通过乘上合适的系数，把这种“损失”补回来，所以比 Xavier 初始化更适合 ReLU。

PyTorch 常见写法有：

torch.nn.init.kaiming_normal_(w)

或者

torch.nn.init.kaiming_uniform_(w)

# with torch.no_grad()的作用是：临时关闭 PyTorch 的自动求导追踪。

也就是说，在这个代码块里面做的张量运算：

  • 不会被加入计算图
  • 不会为之后的反向传播保存中间信息

# 如果不用 torch.no_grad() 会怎样？

如果你直接写：

而 w 本身又是 requires_grad=True 的张量，那么 PyTorch 会试图把这次更新也当成计算图的一部分。

这会带来几个问题：

  • 不必要地构建额外计算图
  • 增加内存开销
  • 可能导致报错
  • 让参数更新和梯度计算纠缠在一起

训练时我们通常不希望“优化器更新参数”也参与求导。

# 2.5 RNNs

RNN（Recurrent Neural Network，循环神经网络）是专门处理序列数据的一类神经网络，比如文本、语音、时间序列。它和普通前馈网络最大的不同是：

RNN 有“记忆”：它在处理当前输入时，不只看当前这个元素，还会结合“前面已经看到的内容”。

比如读一句话：

I grew up in France, I speak fluent ____

当模型读到 fluent 后，想预测下一个词时，前面出现过 France 这个信息就很重要。RNN 的目标就是把这种“前文信息”保存下来。

假设输入序列是：x1, x2, x3, ..., xt`

RNN 会一步一步处理：

  • 第 1 步读 x1
  • 第 2 步读 x2，同时结合上一步的状态
  • 第 3 步读 x3，同时结合前面的状态

它内部会维护一个隐藏状态 h_t，可以理解成“到当前为止的记忆总结”。

核心更新公式通常写成：

ht=f(Wxhxt+Whhht−1+b)h_t = f(W_{xh} x_t + W_{hh} h_{t-1} + b) ht​=f(Wxh​xt​+Whh​ht−1​+b)

  • x_t：当前输入
  • h_{t-1}：上一个时刻的隐藏状态（过去的信息）
  • h_t：当前时刻的新隐藏状态
  • f：激活函数，比如 tanh

如果要输出结果，还会有：

y_t = W_hy h_t + c

所以 RNN 的逻辑其实很像：

当前记忆 = 当前输入 + 过去记忆 的组合

# 为什么 RNN 适合序列

因为序列有顺序关系。

例如：

  • 文本：前面的词会影响后面的词
  • 语音：前面的音节影响当前音节判断
  • 股票/天气时间序列：过去的趋势会影响现在

普通神经网络默认输入彼此独立，不擅长表达这种“前后依赖”；RNN 则天然按时间展开，适合做这件事。

# RNN 的展开图

虽然叫“循环”，训练时通常把它看成沿时间展开的一串重复模块：

x1 -> [RNN] -> h1
x2 -> [RNN] -> h2
x3 -> [RNN] -> h3
...

更准确地说是：

h0 -> h1 -> h2 -> h3 -> ...
       ^     ^     ^
       x1    x2    x3

每个时刻用的是同一套参数。
这点很重要：RNN 在每个时间步共享权重，所以它能处理不同长度的序列。

# RNN 的问题：长期依赖难学

标准 RNN 虽然有记忆，但这个记忆不太擅长记很久以前的信息。

例如一句很长的话里，开头的信息可能到后面就“淡掉了”。
这叫 long-term dependency problem（长期依赖问题）。

根本原因通常和训练时的 梯度消失 / 梯度爆炸 有关。

# 梯度消失

反向传播经过很多时间步后，梯度越来越小，前面位置几乎学不到东西。

# 梯度爆炸

梯度变得特别大，训练不稳定。

所以标准 RNN 在长序列上往往效果一般。

# 为了解决这个问题，出现了 LSTM 和 GRU

这两个可以看作 RNN 的改进版本：

  • LSTM：Long Short-Term Memory
  • GRU：Gated Recurrent Unit

它们通过“门控机制”决定：

  • 什么信息该记住
  • 什么信息该忘掉
  • 什么信息该输出

所以它们比普通 RNN 更擅长处理长距离依赖。

很多时候，别人说“RNN 模型”，实际也常把 LSTM / GRU 放进这个大类里讨论。

# RNN 是怎么训练的

RNN 通常用 BPTT（Backpropagation Through Time，时间反向传播） 来训练。

做法是：

  1. 先把序列按时间展开
  2. 正向传播得到每个时刻输出
  3. 计算损失
  4. 再沿着时间方向反向传播梯度，更新参数

也就是说，本质上还是反向传播，只不过图结构跨了多个时间步。

# 3.2 Self-Supervised Learning

现代机器学习需要大量带标签的数据。但很多时候，获取大量人工标注的数据既具有挑战性，又成本高昂。那么，有没有一种方法能够让机器在没有标签数据集的情况下，自动学习一个能够生成良好视觉表示的模型呢？答案是肯定的——这就是自监督学习（Self-Supervised Learning）！

自监督学习（SSL）使模型能够仅利用给定数据集中的数据，而无需使用其标签，就自动学习一个“良好”的表示空间（representation space）。具体来说，如果我们的数据集由大量图像组成，那么自监督学习能够让模型学习并生成图像的“良好”表示向量（representation vector）。

SSL 方法之所以近年来迅速流行，一个重要原因在于：通过 SSL 学习得到的模型在其他数据集上同样表现良好，也就是说，即使是在模型从未训练过的新数据集上，也能够取得不错的效果。

什么样的表示才算“好”？

一个“好”的表示向量需要能够捕捉图像的重要特征，并反映其与数据集中其他图像之间的关系。

这意味着，数据集中表示语义相似对象的图像应该具有相似的表示向量，而表示不同对象的图像则应该具有不同的表示向量。例如，两张苹果的图片应该具有相似的表示向量，而一张苹果图片和一张香蕉图片则应该具有不同的表示向量。

对比学习：SimCLR

近年来，SimCLR 提出了一种新的架构，利用**对比学习（Contrastive Learning）**来学习高质量的视觉表示。对比学习的目标是：为相似图像学习相似的表示，为不同图像学习不同的表示。

具体来说，对于数据集中的每一张图像，SimCLR 会生成该图像经过两种不同数据增强（augmentation）后的视图，并将这两个视图称为一个正样本对（positive pair）。随后，模型会被鼓励为这对图像生成相似的表示向量。

# Prediction 类别 vs Contrastive 类别

Self-Supervised Learning 里常见有两类方法：

一类是 Prediction-based 方法，另一类是 Contrastive-based 方法。

# 1. Prediction 类别：让模型“预测被隐藏的信息”

Prediction 类别的核心思想是：

从原始数据里故意挖掉一部分信息，让模型根据剩下的内容把它预测回来。

典型例子就是 BERT。

BERT 会拿大量没有标签的句子来训练。训练时，随机把句子中的某些 token mask 掉，然后让模型根据上下文预测被盖住的词。

例如：

我今天去 [MASK] 吃饭。

模型需要根据上下文预测 [MASK] 可能是“学校”“餐厅”“公司”等。

通过这种“填空题”训练，模型就能学到：一个词在上下文中的语义表示，也就是更好的 Embedding / Representation。

所以 Prediction 类方法的重点是：

让模型学会根据上下文恢复或预测原始输入中的某部分信息。

# 2. Contrastive 类别：让模型“区分谁和谁更像”

Contrastive 类别的核心思想是：

不要求模型重建原始输入，而是==希望模型在特征空间里学会区分不同样本==。

也就是说，它不关心模型能不能把原图、原句子完整还原出来，而是关心：

哪些输入应该靠近，哪些输入应该远离。

比如在 SimCLR 里，同一张图片经过两种不同的数据增强后，虽然看起来不完全一样，但它们本质上还是同一张图片，所以它们应该在特征空间里更接近。

而不同图片之间，则应该在特征空间里更远。

因此 Contrastive 类方法的重点是：

让模型学会判断样本之间的相似性和差异性，从而学到有区分能力的 Representation。

总结：

类别 核心任务 是否重建原始输入 学到什么
Prediction 预测被遮住或缺失的内容 通常需要 根据上下文理解输入
Contrastive 拉近相似样本，推远不同样本 不需要 区分不同输入的特征表示
